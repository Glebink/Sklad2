Импорт на склад

Файл .xlsx со столбцами Код и Количество. Обновятся только количества у позиций с совпавшим кодом — названия, разделы и модели не изменятся. Позиции, которых нет в файле, не трогаются.

GitHub-токен (только с правом «gist»)
ID Gist (оставьте пустым — создастся новый)
Как получить токен:
  1. Откройте github.com/settings/tokens
  2. Generate new token → Fine-grained (или classic)
  3. Права: только gist (Read and write)
  4. Скопируйте токен сюда — он хранится только в этом браузере
На каждом устройстве нужно один раз ввести тот же токен и тот же ID Gist (после первого сохранения ID появится в этом поле — скопируйте его на другое устройство).

История сохранений

Что и когда менялось: добавленные позиции, изменённое количество, обмен с сервером. Правки, сделанные в пределах минуты, показываются одной записью. Хранится только на этом устройстве.
